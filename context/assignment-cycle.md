# Assignment cycle

One assignment per week, **due every Tuesday at 5:30 PM**.

## The cycle
Tue (new assignment, class) → Wed, Thu (short sessions) → Fri (off) → Sat, Sun (main blocks) → Mon (finish) → Tue 5:30 PM due

- **Goal:** mostly done by end of Sunday. Monday evening is a buffer, not the plan.
- If it's Saturday and fewer than half the steps are done, the assignment is **behind**. Say so plainly and suggest skipping boxing or moving chores.
- On Monday, only polish and submit, unless it's behind.

## Tracking progress
- Each assignment is a list of steps, in `context/assignments/<assignment>.md`.
- At each check-in, ask which step Khang is on (unless it's Tue/Fri with no session last night).
- Record it in `notes/log.md` as "A6: on step 3 of 5".
- Plan in steps: "Saturday: finish step 3, start step 4", not "work on A6".
- If there's no file for the current assignment, ask Khang to add it. Don't invent steps.
